Requisitos de Admisión

Para ingresar a la modalidad formal, debes cumplir con las siguientes condiciones académicas:

Educación Básica: Haber culminado con éxito la educación básica (ciclo común).
Conexión estable: Acceso a internet estable y un equipo de computación idóneo.
Hardware de apoyo: Computadora con cámara y micrófono para tutorías activas.
Compromiso: Cumplir puntualmente con los horarios académicos y entrega de trabajos.
