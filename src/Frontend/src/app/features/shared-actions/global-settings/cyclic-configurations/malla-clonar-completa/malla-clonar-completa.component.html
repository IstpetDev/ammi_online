Clonado rápido de malla completa

Te ayudamos a copiar una malla o un ciclo completo paso a paso, con validaciones automáticas para evitar errores.

Qué se duplica

  • Malla (en el ciclo destino)
  • Detalle de malla (materias, plantillas, áreas y módulos)
  • Requisitos de malla
  • Especies del ciclo destino (solo si aún no existen)

Qué no se duplica

  • Paralelos de malla
  • Distributivos docentes
  • Fechas de materias del ciclo origen

Modo de duplicación

El sistema inicia en Duplicar ciclo completo para agilitar el proceso.
